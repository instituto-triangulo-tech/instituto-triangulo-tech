## Missão

O Instituto Triângulo Tech é um instituto de pesquisa tecnológico aberto que investiga
como a inteligência artificial pode operar a vida real: agentes autônomos, dados
pessoais sob controle do indivíduo e ambientes inteligentes. Pesquisa aplicada,
publicada abertamente, construída sobre sistemas que rodam de verdade.

**Site institucional:** [instituto.triangulo.tech](https://instituto.triangulo.tech)

## Os três eixos de pesquisa

1. **Agentes de IA autônomos** — arquitetura, orquestração, avaliação e segurança de
   agentes que decidem e agem no mundo real. Semente de uma futura certificadora de
   segurança de agentes de IA.
2. **Soberania de dados pessoais** — um "Life OS": memória pessoal e processamento
   local-first, com os dados sob controle de quem os gerou, não de uma nuvem de
   terceiros.
3. **Ambientes inteligentes** — automação residencial com IA, usando a própria casa
   como um laboratório vivo, rodando todo dia, num lugar real.

## Licenciamento

O ITT publica sob licenças diferentes conforme o tipo de material:

| Material | Licença | Por quê |
|---|---|---|
| Relatórios técnicos (ITT-TR) | **CC BY 4.0**, com DOI via Zenodo | Conteúdo de pesquisa: qualquer um pode reusar/adaptar, desde que credite a fonte — padrão de publicação acadêmica aberta. |
| Código — utilitários gerais | **MIT** | Permissiva, sem restrição prática de uso, para ferramentas que não têm implicação de segurança. |
| Código — segurança / controle de acesso | **Apache 2.0** | Igualmente permissiva, mas inclui concessão explícita de patente e cláusula de proteção contra litígio — mais adequada quando o código toca autenticação, autorização ou sandboxing. |

Cada repositório declara sua própria licença no arquivo `LICENSE`; esta tabela é só
o guia de critério.

## Marca

O nome e o símbolo do Instituto Triângulo Tech não estão cobertos pelas licenças de
código/conteúdo; não os utilize de forma a sugerir endosso oficial.
